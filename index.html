001 — The problem

Multi-LLM critique is a double-edged tool.

External feedback can repair genuine errors. But accepting flawed critique causes models to abandon correct derivations they'd already reached on their own. Self-refinement is unreliable, and assuming critique is uniformly beneficial degrades overall performance without a way to gate it.

Core question — can lightweight, pre-revision signals reliably predict when a solver should accept a critic's feedback, before any revision is made?

Objectives

  • Directional asymmetry — does critique benefit depend on which model solves and which one critiques?
  • Failure mechanism — is asymmetry driven by correction effectiveness, or by harmful critiques of already-correct answers?
  • Predictive signals — do directional-pairing features out-predict critique-derived features?

002 — Pipeline

Solve independently. Evaluate. Gate. Revise only if the gate says so.

Four stages: Solve (independent, no cross-contamination) → Evaluate (critic compares answers, returns a verdict + proposed answer) → Gate (a logistic model trained on pre-revision features predicts if revision helps) → Validate (5-fold StratifiedGroupKFold by question, then one frozen held-out pass). Dataset: GSM8K. Models: Qwen2.5-3B-Instruct and Llama-3.2-3B-Instruct, run in both solver/critic directions.

006 — Future directions

  • Scale evaluation datasets — expand held-out benchmarks to overcome statistical underpowering and validate directional reproducibility.
  • Integrate LLM-as-judge — replace shallow text-length proxies with automated critique-quality scoring to capture nuanced reasoning errors.
  • Expand model heterogeneity — benchmark diverse model families to test cross-architecture generalization.
  • Broaden beyond disagreement — extend the selective gating framework to consensus and agreement scenarios.
  • Inference-time deployment — package the learned gate into a plug-and-play wrapper requiring zero model retraining.
